### Featured Projects

#### 01. SPredicty
**AI-Powered Skill Demand Forecasting**

An ML-based workforce intelligence project that analyses job-market data to forecast emerging skill demands.

- Built around 30,000+ real-world job postings.
- Engineered 20+ predictive features.
- Implemented LightGBM-based forecasting.
- Supports recursive and multi-horizon predictions up to 60 days.
- Includes modular data-processing and evaluation pipelines.

**Stack:** Python · LightGBM · Scikit-learn · Machine Learning

#### 02. WayAble
**Accessibility-Focused Journey Planning**

A web application focused on making everyday journeys more accessible by evaluating the accessibility of the entire journey, not just the destination.

- Accessible place discovery.
- Journey accessibility checker.
- Assistance requests and issue reporting.
- Interactive maps and accessibility preferences.

**Stack:** React · Vite · Tailwind CSS · Leaflet · OpenStreetMap
